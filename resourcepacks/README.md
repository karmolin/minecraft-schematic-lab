# Minecraft Java 1.12.2 材质包

把 ZIP 或已解压的材质包文件夹放在这里，在网页“材质包”中选择。列表每 5 秒更新，也可以点击“刷新”。无需重启或重新构建。

- 使用 `pack_format: 3`。根目录应包含 `pack.mcmeta` 和 `assets/`；ZIP 多套一层文件夹也可识别。
- 中文 ZIP 文件名可用。ZIP **内部**文件名应使用 UTF-8，避免 GBK 导致的读取错误。
- 原版底层资源：将 **Java 1.12.2 客户端 JAR** 复制为 `.base/minecraft-1.12.2.jar`。也可用环境变量 `MINECRAFT_112_JAR` 指定现有 JAR。
- 原版模型与贴图用于补齐资源包未覆盖的内容。用户资源包不会隐式回退到 Pixel Perfection CE；它是一个独立的预览选项。
- 文件保存在本机，不随项目发布。`RESOURCE_PACKS_DIR` 可指定另一个材质包目录。

首版范围：1.12.2 原版方块贴图与标准 JSON 方块模型、常见方向和上下半部。动画暂取配置中的第一帧；随机模型取第一项；草叶染色采用固定预览颜色。特殊方块实体、OptiFine、光影、龙核模型暂不支持。缺失/不支持的方块会在网页列出。

切换材质包不会改动建筑的方块 ID 或导出文件。模板识别问题单独处理。网页“截图”保存所选材质的实际画面；MCP `render_image` 仍是原有纯色等轴图。
