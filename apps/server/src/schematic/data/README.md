# Legacy block names

`legacy-blocks.json` is the `blocks` table from PrismarineJS/minecraft-data,
`data/pc/common/legacy.json`, retrieved 2026-09-09 from
https://cdn.jsdelivr.net/gh/PrismarineJS/minecraft-data@master/data/pc/common/legacy.json.
It maps pre-flattening numeric ID/data to modern block-state names for preview.
Original ID/data are retained separately per imported cell for legacy re-export.
Neighbor-dependent properties in this table are representatives, not stored metadata.

Source: https://github.com/PrismarineJS/minecraft-data (MIT).
